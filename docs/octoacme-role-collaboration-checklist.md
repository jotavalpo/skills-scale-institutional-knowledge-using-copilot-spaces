# OctoAcme — Role Collaboration Checklist

Use this checklist to ensure cross-functional role clarity and handoffs are explicit across the project lifecycle.

## Phase Checklist

### 1) Initiation
- [ ] Confirm core role ownership: Project Manager (PM), Product Manager (PdM), Developers, QA Specialist
- [ ] Identify additional required roles: UX/UI Designer, Data Analyst, Technical Writer, Customer Success Lead
- [ ] Align on communication cadence and decision owners across PM, PdM, and delivery roles
- [ ] Output: Project One-pager with role map and initial collaboration touchpoints

### 2) Planning
- [ ] UX/UI Designer reviews scope and provides wireframes/prototypes before implementation starts
- [ ] QA Specialist drafts the test approach and risks per milestone
- [ ] Data Analyst defines KPIs and tracking requirements with PdM and Developers
- [ ] Technical Writer identifies documentation deliverables tied to roadmap items
- [ ] Output: Prioritized backlog with linked design assets, QA plan, KPI definitions, and documentation plan

### 3) Execution
- [ ] Developers, UX/UI Designer, and QA Specialist run regular build-review-validate loops
- [ ] PM tracks cross-role dependencies and escalates blocked handoffs
- [ ] Data Analyst monitors dashboard signals and flags trend-based risks
- [ ] Technical Writer drafts updates as features stabilize; Customer Success Lead prepares enablement inputs
- [ ] Output: Updated project board, defect log, dashboard updates, draft documentation

### 4) Release
- [ ] QA Specialist provides explicit QA signoff (or documented risks/waivers)
- [ ] Technical Writer completes release notes and user-facing updates
- [ ] Customer Success Lead validates rollout communication and support readiness
- [ ] PM and PdM confirm go/no-go decision with cross-functional inputs
- [ ] Output: QA signoff record, release notes, deployment communication package

### 5) Retro
- [ ] Review cross-role collaboration outcomes and missed handoffs
- [ ] Evaluate KPI outcomes and customer feedback with Data Analyst and Customer Success Lead
- [ ] Capture documentation/process gaps with Technical Writer and PM
- [ ] Output: Retrospective actions with named owners and due dates

## Artifact RACI (lightweight)

Legend: **R** = Responsible, **A** = Accountable, **C** = Consulted, **I** = Informed
